# PRD：博丽神社防卫战

## 目标

用一个能玩的小游戏检验一套分工原则：代码负责有状态、需要精确或需要验收的部分（规则、坐标、弹幕、平衡、音乐时值），生成模型只负责外观（地图美术、角色立绘）。游戏本身首先是给作者自己玩的。

## 用户

东方 Project 玩家，在桌面浏览器或横屏手机上打开网页直接玩，不需要安装。

## 需求

- 标准塔防：固定参道，十个石台，十波敌人，最后一波 Boss 琪露诺。
- 三个角色塔：灵梦（追踪）、魔理沙（散射）、咲夜（快速 + 减速），可升级到三星、可出售。
- 每个角色一张符卡，波次中手动发动，有冷却，有立绘 cut-in。
- 画风：同人精修风。美术全部由 GPT Image 生成，角色风格一致。
- 音乐：关卡曲和 Boss 曲，明显的 ZUN 风格；Boss 登场时切换。
- 体验：波次清空后自动倒计时开始下一波，可随时立即开始；可暂停，暂停时仍能摆塔。
- 手机可玩：触屏操作、横屏提示、iOS 音频可用。

## 成功标准

- 打开 GitHub Pages 链接即可玩完十波，无控制台错误。
- 平衡护栏成立：混合阵容能赢；不建塔、只建两座塔、不放符卡都会输；单一角色不优于混合阵容。
- 作者试玩后认为好玩、画风统一、音乐像 ZUN。后一条只能由人判断。
